**# Caffeline - Cat Cafe Website**

A mock cat cafe responsive multi-page website made for CSS0027L. Built with HTML, CSS, and JavaScript.



**## Pages**

\- `caffeline.html` — Home page with hero banner, featured items, and café menu

\- `aboutus.html` — Café story and highlights

\- `contact.html` — Contact details and inquiry form

\- `caffeline.css` — Shared responsive stylesheet for all pages



**## Features**

\- Responsive layout for desktop, tablet, and mobile

\- Categorized food and drinks menu with hover effects

\- Interactive contact form



**## How to Run**

1\. Download or clone the project folder.

2\. Keep all image files in the same folder as the HTML files.

3\. Open `caffeline.html` in your browser.
